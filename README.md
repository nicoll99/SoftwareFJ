# Software FJ

Sistema orientado a objetos desarrollado en Python para la gestión de clientes, servicios y reservas.

## Características

- Programación orientada a objetos
- Herencia
- Polimorfismo
- Encapsulación
- Clases abstractas
- Manejo avanzado de excepciones
- Registro de logs
- Sin uso de base de datos

## Servicios implementados

- Reserva de salas
- Alquiler de equipos
- Asesorías especializadas

## Tecnologías utilizadas

- Python
- GitHub
- Visual Studio Code

## Cómo ejecutar el sistema

1. Abrir el proyecto en Visual Studio Code.
2. Ejecutar el archivo:

python software_fj.py
